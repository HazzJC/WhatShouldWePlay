# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-19

### Added
- **Plan Workspace**: Anonymous, zero-login group availability heatmaps allowing guests to vote on dates/times without friction.
- **Pick Workspace**: Shared game library catalog matching and scoring engine that ranks games everyone owns.
- **Discord Bot Integration**: Command registration and webhook notifications for group scheduling.
- **Authentication**: Optional Google OAuth login for persistent game libraries and recurring group saves.
- **Test Suite**: 163 automated unit and integration tests covering scheduling algorithms and voting logic.
- **Live Deployment**: Production deployment on Vercel at [what-should-we-play-chi.vercel.app](https://what-should-we-play-chi.vercel.app).
